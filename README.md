# Inkora💜

> **Ideas worth reading. Conversations worth joining.**

Inkora is a full-stack interactive blog platform where users can discover articles, read, like, comment, and participate in discussions. Admins can manage articles, categories, users, likes, comments, and replies through a dedicated dashboard.

## Live Demo

🌐 **Live:** https://inkora-pf64.onrender.com
💻 **GitHub:** https://github.com/YerraboinaManeesha/Inkora

## Features

* User registration and JWT authentication
* Browse, search, and filter articles
* Read full articles
* Like and unlike articles
* Add and delete comments
* Admin replies to comments
* Admin article and category management
* User management
* Like and comment management
* Light/Dark mode
* Responsive editorial-style UI

## Tech Stack

**Frontend:** React.js, Vite, JavaScript, Tailwind CSS, React Router, Axios
**Backend:** Node.js, Express.js, REST APIs, JWT, bcrypt
**Database:** MongoDB, MongoDB Atlas, Mongoose
**Deployment:** Render

## Local Setup

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Create `.env` files using the provided `.env.example` files and configure the required environment variables.

## Deployment

* **Frontend:** Render Static Site
* **Backend:** Render Web Service
* **Database:** MongoDB Atlas
